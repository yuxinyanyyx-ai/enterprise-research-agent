4. 等真实 Trace 表明延迟、错误和成本维度确有价值后，再评估是否建设
   Dashboard。

## 验收条件

- 不得从本地估算值推断实际 Token 数。
- 不得把未知用量或未知价格折算为零成本。
- 重试次数只表示统一重试入口实际控制的重试。
- 并发请求必须保持各自独立的 Trace 和 Request 标识符。
- Trace 写入失败不得影响应用原有业务行为。
- Trace 记录中不得包含 Prompt、源文件内容、凭证或未受限的工具参数。
